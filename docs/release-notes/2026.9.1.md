# Release Notes 2026.9.1

- Implemented [Mastodon CSV import](https://docs.joinmastodon.org/user/moving/#export). You can now go to the *Import OPML* page and import a CSV file from Mastodon export. It behaves similar to a OPML import in which a list of feeds will be shown and you can select which ones to import. Mastodon feeds will have the tag "🐘" automatically applied to them but you can change that before or after import.
